# Beginner Web Project

A simple beginner-friendly web project using HTML, CSS, and JavaScript.

## Features

- Clean, responsive layout
- Dark mode toggle
- Vanilla JavaScript (no frameworks)

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Click the "Toggle Background" button to switch themes

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
