# Beginner Web Project (Python)

A simple beginner-friendly web project built with Python and Flask.

## Features

- Clean, responsive layout
- Dark mode toggle
- Flask backend serving templates and static files

## Getting Started

1. Download or Clone this project
   - **Option A: Download ZIP**: Go to https://github.com/sometri/beginner-web-py -> Click "Code" -> "Download ZIP" -> Extract it
   - **Option B: Clone with Git**: Open terminal and run `git clone https://github.com/sometri/beginner-web-py.git`
2. Go to project folder: `cd beginner-web-py`
3. Create a virtual environment: `python -m venv .venv`
4. Activate it:
   - Windows: `.venv\Scripts\activate`
   - Mac/Linux: `source .venv/bin/activate`
5. Install dependencies: `pip install -r requirements.txt`
6. Run the app: `python app.py`
7. Open http://localhost:5000 in your browser
