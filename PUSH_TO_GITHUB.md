# Push to GitHub Guide

To push this **beginner-web-py** project to your own GitHub repository, follow the step-by-step guide below:

**👉 [Click here to open the full guide](docs/PUSH_TO_GITHUB.md)**

## Quick Summary (for those who already know Git)

If you just need the commands quickly, replace the placeholders with your own info:

```bash
# 1. Go to project folder
cd path/to/your/beginner-web-py

# 2. Set your identity (only once per PC)
git config user.name "YOUR_GITHUB_USERNAME"
git config user.email "your_email@gmail.com"

# 3. Initialize and push
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/beginner-web-py.git
git push -u origin main
```

**Note:** The full detailed guide with images-like steps, public/private repo options, authentication help is in [`docs/PUSH_TO_GITHUB.md`](docs/PUSH_TO_GITHUB.md).
